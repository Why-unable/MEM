# 硕士开题报告资料包

> 用途：把 `Agent Memory 2025+` 的文献证据、baseline 时间轴和实验设置，收敛成可执行的硕士开题方案。
> 当前状态：已选择方向 B（VikingMem 后续：记忆冲突、可信更新与回滚）；待补学校模板、导师方向和可用算力。
> 更新时间：2026-11-27

## 当前建议

**首选题目：**

> 面向知识更新的可追溯事件—实体记忆冲突消解与回滚方法研究

**备选题目：**

> 预算约束下长期对话智能体的自适应记忆路由与证据回退方法研究

首选方向的核心判断是：

> VikingMem 已经把 event + entity Memory Base 做成生产级系统，但“实体状态如何冲突检测、可信更新、保留 provenance、支持回滚”仍没有被充分解决。

这个方向的承接关系是：

```text
VikingMem 的 event + entity
  → 带时间有效期与来源的 claim set
  → 冲突检测与消解
  → 版本化实体状态
  → provenance / audit / rollback
```

它比直接复刻 VikingMem 更适合硕士论文，因为新增问题明确，且仍可复用 LongMemEval、LoCoMo、PersistBench 等公开评测。

## 与 MEM 现有材料的对应关系

写作时应优先使用这些内部材料：

- 研究动态：`个人理解/路线分类.md`
- 逐篇证据：`vault/10_Papers/evidence/INDEX.md`
- baseline 与数据集：`vault/40_Maps/Agent Memory 2025+ Baseline Timeline.md`
- 实验设置全景：`maps/agent-memory-2025/EXPERIMENT_LANDSCAPE.md`
- 主线综合：`vault/20_Topics/Mainline Overview.md`
- 研究问题：`RESEARCH_QUESTIONS.md` 与 `vault/30_Ideas/Agent Memory Research Questions.md`

## 推荐使用顺序

1. 先读 `01_选题方法与方向评估.md`，确认题目属于哪条研究线。
2. 用 `05_VikingMem后续研究与方向B设计.md` 和导师讨论可行性与算力。
3. 取得学校模板后，用 `04_开题报告初稿模板.md` 逐节填写。
4. 用 `02_国内开题报告写作规范.md` 检查长度、结构和论证深度。
5. 用 `07_下一步_导师讨论版.md` 准备 2 页导师讨论稿，确认方向、资源和范围。
6. 导师确认后，再把题目、研究问题、实验矩阵同步回 `RESEARCH_QUESTIONS.md` 和 `RESEARCH_LOG.md`。

## 开题前还需要确认

- [ ] 学校/学院是否有固定模板、字数和参考文献格式
- [ ] 学术硕士还是专业硕士
- [ ] 导师更偏系统、评测、安全还是机器学习方法
- [ ] 可用 GPU、API 预算和实验周期
- [ ] 是否必须与导师现有项目结合
- [ ] 开题时间与中期检查/预答辩时间

## 使用边界

- 本资料包是选题与研究设计辅助，不是学校正式模板。
- 里面的篇幅建议是通用经验值，学校有明确规定时以学校规定为准。
- 推荐题目仍需结合导师方向、实验室资源和你的可实现性做最终调整。
- 开题报告中的关键文献结论应回到 `vault/10_Papers/evidence/` 的页码级证据，不直接引用二手总结。
