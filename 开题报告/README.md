## 与 MEM 现有材料的对应关系

写作时应优先使用这些内部材料：

- 研究动态：`个人理解/路线分类.md`
- 逐篇证据：`vault/10_Papers/evidence/INDEX.md`
- baseline 与数据集：`vault/40_Maps/Agent Memory 2025+ Baseline Timeline.md`
- 实验设置全景：`maps/agent-memory-2025/EXPERIMENT_LANDSCAPE.md`
- 主线综合：`vault/20_Topics/Mainline Overview.md`
- 研究问题：`RESEARCH_QUESTIONS.md` 与 `vault/30_Ideas/Agent Memory Research Questions.md`

## 推荐使用顺序

1. 先读 `01_选题方法与方向评估.md`，确认题目属于哪条研究线。
2. 用 `08_方向B_硕士论文开题报告.md` 和导师讨论当前方法、评测和可用资源。
3. 按学院提纲整理当前正文及所需的个人进展材料。
4. 用 `02_国内开题报告写作规范.md` 检查长度、结构和论证深度。
5. 用 `07_下一步_导师讨论版.md` 准备 2 页导师讨论稿，确认方向、资源和范围。
6. 导师确认后，再把题目、研究问题、实验矩阵同步回 `RESEARCH_QUESTIONS.md` 和 `RESEARCH_LOG.md`。

## 开题前还需要确认

- [ ] 学校/学院是否有固定模板、字数和参考文献格式
- [ ] 学术硕士还是专业硕士
- [ ] 导师更偏系统、评测、安全还是机器学习方法
- [ ] 可用 GPU、API 预算和实验周期
- [ ] 是否必须与导师现有项目结合
- [ ] 开题时间与中期检查/预答辩时间

## 使用边界

- 本资料包是选题与研究设计辅助，不是学校正式模板。
- 里面的篇幅建议是通用经验值，学校有明确规定时以学校规定为准。
- 推荐题目仍需结合导师方向、实验室资源和你的可实现性做最终调整。
- 开题报告中的关键文献结论应回到 `vault/10_Papers/evidence/` 的页码级证据，不直接引用二手总结。
