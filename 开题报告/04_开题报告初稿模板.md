# 题目

**预算约束下长期对话智能体的自适应记忆路由与证据回退方法研究**

备选题目：

- 面向知识更新的 LLM Agent 记忆冲突检测与可追溯巩固方法研究
- 面向长期交互智能体的可审计记忆遗忘与治理机制研究

---

## 一、研究背景与问题

### 1.1 研究背景

> 提示：写长期记忆为什么是 LLM agent 的关键问题；不要只写“大模型很重要”。

### 1.2 现有系统的失败现象

> 提示：从 MEM 的 baseline timeline 和 evidence 中找具体反例。例如：
> - 结构化记忆在 multi-hop / temporal 上更强，但在 single-hop / knowledge update 上不一定赢；
> - 摘要记忆成本低，但可能丢失原始证据；
> - 记忆系统准确率提高，但 token 和延迟不可接受。

### 1.3 研究问题

> 提示：1 个主问题 + 2–3 个子问题。

---

## 二、国内外研究现状

### 2.1 结构记忆与长上下文

> 代表工作：A-Mem、G-Memory、MAGMA、MemGAS、MRAgent、HippoRAG 2、VikingMem
> 关键判断：结构记忆是否真的优于长上下文？哪些任务会输？

### 2.2 记忆写入、更新与遗忘

> 代表工作：Mem0、MemoryOS、RecMem、TiMem、TierMem、Nemori、PersistBench
> 关键判断：何时写入、何时巩固、何时回退、何时遗忘？

### 2.3 记忆访问策略与成本

> 代表工作：TierMem、MRAgent、Evoking、MemGAS、LightMem、Hippocampus
> 关键判断：准确率、token、latency、storage 的 Pareto 前沿是什么？

### 2.4 记忆安全与治理

> 代表工作：MEXTRA、MINJA、InjecMEM、eTAMP、PersistBench
> 关键判断：写入权限、provenance、删除、回滚和隐私如何进入系统设计？

### 2.5 研究现状评述

> 提示：总结 3 个缺口，不要写“研究还不够多”。
> 例如：
> 1. 结构记忆与访问策略通常分开研究；
> 2. 摘要记忆与原始证据之间缺少 query-time 充分性判断；
> 3. 准确率、成本、证据保留和更新正确性缺少统一评测。

---

## 三、研究问题与研究目标

### 3.1 主问题

> 预算约束下，长期记忆系统应如何选择记忆访问路径？

### 3.2 子问题

1. 如何判断当前摘要/检索证据是否足够？
2. 如何在 full-context、RAG、图记忆和原始证据之间做成本感知路由？
3. 如何保留 provenance 并评价证据回退的效果？

### 3.3 研究目标

> 提出一套可实现的记忆路由与证据回退框架，并在公开长期记忆 benchmark 上验证 accuracy–cost–evidence 的 Pareto 改进。

---

## 四、研究内容

### 4.1 多层记忆表示与证据链

> 写清楚：摘要层、原始证据层、关系层分别存什么；provenance 如何连接。

### 4.2 查询级充分性判断与路由

> 写清楚：输入、判断信号、动作空间、输出和失败降级。

### 4.3 证据回退与联合评测

> 写清楚：如何回退到原始 turn/page/event；如何组装最小充分证据；如何评价。

---

## 五、研究方法与技术路线

### 5.1 总体技术路线

```text
输入
 → 事件/实体抽取
 → 多层记忆组织
 → 查询级充分性判断
 → 路由选择
 → 原始证据回退
 → 最小证据组装
 → 答案生成与证据链
```

### 5.2 关键方法

> 提示：至少写清楚规则 router / 分类器 router / LLM policy 的选择，以及为什么当前阶段选哪一个。

### 5.3 实现方案

> 提示：说明 memory store、embedding、retrieval、graph、page/turn 索引和日志记录。

## 六、实验设计

### 6.1 数据集

- LoCoMo
- LongMemEval
- MemoryAgentBench
- 可选的 PersistBench / 自建冲突子集

### 6.2 基线

- No-Memory
- Full-Context
- Naive RAG
- A-Mem
- Mem0 或 MemoryOS
- TierMem
- 本文方法

### 6.3 指标

- F1 / LLM-Judge
- evidence recall
- knowledge-update accuracy
- input/total tokens
- p50/p95 latency
- storage / build cost

### 6.4 消融

> 写清楚：去掉 router、去掉 provenance、固定预算、不同 router 实现、单层 vs 多层。

### 6.5 风险与备选实验

> 写清楚：baseline 复现失败怎么办、主方法不占优怎么办、数据不足怎么办。

## 七、预期创新点

1. 提出预算感知的多层记忆路由框架。
2. 设计 provenance-aware 的原始证据回退机制。
3. 构建 accuracy–cost–evidence 联合评测协议。

> 提示：创新点控制在 2–3 个，每个都能对应实验。

## 八、可行性分析

### 8.1 技术可行性

> 不训练大模型、基于现有 memory store 和公开 benchmark。

### 8.2 数据可行性

> 公开数据 + 自建小规模冲突/更新子集。

### 8.3 时间可行性

> 12 个月安排：baseline 复现 → 原型 → 主实验 → 消融 → 写作。
