## 1. 存储方式：记忆到底以什么形态存在

- **原始文本 / turn / session / segment 存储**：先保留可检索的原始交互或主题段，再做摘要或索引 （SeCom 2025-04；MemoryOS 2025-11；LightMem 2026-04；MemGAS 2026-04；E-mem 2026-07；EMA 2026-07；LightMem (SLM) 2026-07；RecMem 2026-07；SimpleMem 2026-07；TiMem 2026-07；TierMem 2026-10）
- **原子笔记 / 结构化文本**：把交互写成带关键词、标签、上下文和链接的 note （A-Mem 2025-12；G-Memory 2025-12；REMem 2026-04；MRAgent 2026-07；Nemori 2026-07）
- **向量索引**：用 dense embedding 做语义近邻检索 （M+ 2025-07；Mem0 2025-10；A-Mem 2025-12；LightMem 2026-04；MemGAS 2026-04；Hippocampus 2026-05；LightMem (SLM) 2026-07；MRAgent 2026-07；TierMem 2026-10）
- **实体 / 关系图**：把实体、事件、关系和属性显式建成图 （HippoRAG 2 2025-07；REMem 2026-04；GAM 2026-07；MAGMA 2026-07；MRAgent 2026-07；MemRec 2026-07）
- **图 + 文本混合存储**：图负责关系和导航，文本负责原始证据或内容重构 （HippoRAG 2 2025-07；EverMemOS 2026-07；GAM 2026-07；MAGMA 2026-07；MRAgent 2026-07；TierMem 2026-10）
- **层次 / OS 式存储**：用 short/mid/long-term 或 task/subtask 等层级组织记忆 （MemoryOS 2025-11；G-Memory 2025-12；MemGAS 2026-04；EverMemOS 2026-07；LightWM 2026-07；TiMem 2026-07；TierMem 2026-10）
- **参数化 / latent memory**：把长期信息压进模型参数或 hidden state，而不是外部数据库 （M+ 2025-07）
- **多模态记忆**：以 entity 为中心保存视觉、听觉和文本经验 （M3-Agent 2026-04）
- **程序性 / 技能记忆**：保存“怎么做”的经验、策略和可复用技能 （G-Memory 2025-12；ReasoningBank 2026-04；ReMe 2026-07）
- **协作 / 共享记忆**：保存用户-物品关系、团队中间状态或跨团队共享经验 （G-Memory 2025-12；LTS 2026-07；MemRec 2026-07）

## 2. 组织方式：记忆之间怎么连、怎么分层

- **相似度建边**：把语义相近的记忆块连接起来，形成可扩展的关联网络 （Mem0 2025-10；A-Mem 2025-12；LightMem 2026-04；MemGAS 2026-04；Hippocampus 2026-05；LightMem (SLM) 2026-07；MRAgent 2026-07；TierMem 2026-10）
- **分层 / 多粒度组织**：turn、session、segment、summary、keyword 等不同粒度并存 （SeCom 2025-04；MemoryOS 2025-11；G-Memory 2025-12；MemGAS 2026-04；EverMemOS 2026-07；LightWM 2026-07；TiMem 2026-07；TierMem 2026-10）
- **时间 / 因果 / 实体关系**：把“何时、为何、涉及谁”作为独立关系维度 （EM-LLM 2025-04；ARTEM 2026-01；REMem 2026-04；GAM 2026-07；MAGMA 2026-07；TiMem 2026-07）
- **事件分割**：按语义/时间边界把连续交互切成事件，而不是固定 chunk （EM-LLM 2025-04；SeCom 2025-04；ARTEM 2026-01；REMem 2026-04；E-mem 2026-07；GAM 2026-07；TiMem 2026-07）
- **主题 / scene 组织**：把事件归并成主题、scene 或 topic network （SeCom 2025-04；MemGAS 2026-04；EverMemOS 2026-07；GAM 2026-07）
- **Cue–Tag–Content 结构**：用 cue 触发 tag，再由 tag 指向 content，避免直接 N-hop 爆炸 （MRAgent 2026-07）
- **Provenance / 证据链接**：summary 与 raw evidence 之间保留可追溯链接 （TierMem 2026-10）
- **协作图组织**：把用户、物品、邻居和共现关系组织成 collaborative graph （G-Memory 2025-12；LTS 2026-07；MemRec 2026-07）
- **层间传播**：高层经验向下影响检索，低层证据向上更新高层结构 （MemoryOS 2025-11；G-Memory 2025-12；MemGAS 2026-04；TiMem 2026-07；TierMem 2026-10）
- **参数化组织**：通过 co-trained retriever 访问参数 memory pool （M+ 2025-07）

## 3. 写入、更新与巩固：什么时候把经验变成长期记忆

- **即时 / 逐条写入**：每条新交互都抽取、总结或更新 memory （Mem0 2025-10；MemoryOS 2025-11；A-Mem 2025-12；MemGAS 2026-04；ReasoningBank 2026-04；EverMemOS 2026-07；MRAgent 2026-07；ReMe 2026-07）
- **延迟 / 复发触发写入**：先进入轻量层，只有反复出现或足够重要时才调用 LLM 巩固 （LightMem 2026-04；EverMemOS 2026-07；LightMem (SLM) 2026-07；Nemori 2026-07；RecMem 2026-07）
- **语义偏移触发整合**：只有话题/事件发生明显偏移时，才把短期事件合并到长期结构 （SeCom 2025-04；EverMemOS 2026-07；GAM 2026-07；TiMem 2026-07）
- **预测误差触发蒸馏**：用未来可预测性/预测误差判断哪些经验值得保留 （Nemori 2026-07）
- **在线 / 离线解耦**：在线只做轻量写入，离线做高成本 consolidation （LightMem 2026-04；EverMemOS 2026-07；LightMem (SLM) 2026-07；LightWM 2026-07）
- **验证后写回**：只把有 grounding 的结论写回快层，并保留 provenance （TierMem 2026-10）
- **旧记忆更新**：新信息可以改写旧记忆的描述、标签、关系或 profile （Mem0 2025-10；MemoryOS 2025-11；A-Mem 2025-12；G-Memory 2025-12；EverMemOS 2026-07；ReMe 2026-07）
- **删除 / 过滤动作**：把 delete、filter、prune 作为显式操作 （AgeMem 2026-07；EMA 2026-07；Memory-R1 2026-07；ReMe 2026-07）
- **过期 / 冲突 / 回滚**：长期记忆需要版本化、冲突检测和可回滚机制 （MemoryAgentBench 2026-04；EverMemOS 2026-07；PersistBench 2026-07；TierMem 2026-10）

## 4. 读取、检索与重构：query 到来时怎么找证据

- **向量 top-k**：query embedding 与 memory embedding 做相似度检索 （M+ 2025-07；Mem0 2025-10；A-Mem 2025-12；LightMem 2026-04；MemGAS 2026-04；Hippocampus 2026-05；LightMem (SLM) 2026-07；MRAgent 2026-07；TierMem 2026-10）
- **稠密 + 稀疏混合检索**：同时利用语义相似度、关键词、时间等信号 （HippoRAG 2 2025-07；REMem 2026-04；MAGMA 2026-07；TierMem 2026-10）
- **Personalized PageRank**：在图上传播 relevance，聚合 passage/实体证据 （HippoRAG 2 2025-07；MemGAS 2026-04）
- **Router / gating**：先判断“够不够、走哪条路、用哪一层”，再决定检索深度 （Evoking/RF-Mem 2026-04；MemGAS 2026-04；EMA 2026-07；LTS 2026-07；TierMem 2026-10）
- **主动重构**：检索不是一次 top-k，而是根据中间证据多轮选择、扩展、剪枝 （Evoking/RF-Mem 2026-04；E-mem 2026-07；MRAgent 2026-07；TierMem 2026-10）
- **Agentic retriever**：用工具进行 semantic/lexical/graph/temporal 多步检索 （REMem 2026-04；E-mem 2026-07；EverMemOS 2026-07；MRAgent 2026-07）
- **双过程检索**：familiarity 快检索 + recollection 慢重构 （Evoking/RF-Mem 2026-04）
- **行动 / 角色条件化检索**：检索结果按用户 persona、agent 角色或任务 action 定制 （G-Memory 2025-12；M3-Agent 2026-04；LTS 2026-07；PersonaAgent 2026-07）
- **多轮推理式检索**：在长视频、Web、长期任务中边推理边取证据 （M3-Agent 2026-04；ReasoningBank 2026-04；E-mem 2026-07；MRAgent 2026-07）
- **固定检索预算**：在 token/latency 约束下决定检索多少、检索多深 （Evoking/RF-Mem 2026-04；LightMem 2026-04；MemGAS 2026-04；LightMem (SLM) 2026-07；TierMem 2026-10）

## 5. 学习与训练：哪些东西可以被学习

- **Training-free 记忆架构**：不改模型参数，只靠 LLM 组织/检索/巩固 （HippoRAG 2 2025-07；MemoryOS 2025-11；A-Mem 2025-12；G-Memory 2025-12；Evoking/RF-Mem 2026-04；LightMem 2026-04；MemGAS 2026-04；EverMemOS 2026-07；GAM 2026-07；LightMem (SLM) 2026-07；MAGMA 2026-07；MRAgent 2026-07；Nemori 2026-07；PersonaAgent 2026-07；SimpleMem 2026-07）
- **可学习 / 可进化的记忆策略**：把写入、检索、更新、删除等操作作为 policy 学习，或直接进化记忆架构 （M3-Agent 2026-04；MemAgent 2026-04；AgeMem 2026-07；LTS 2026-07；MemEvolve 2026-07；Memory-R1 2026-07；UMEM 2026-07）
- **元进化记忆架构**：不仅学经验，还进化 memory architecture 本身 （MemEvolve 2026-07）
- **联合抽取 + 管理**：同时优化“抽取出什么”和“怎么管理” （AgeMem 2026-07；UMEM 2026-07）
- **学习型 router / controller**：学习何时升级、何时共享、何时过滤 （EMA 2026-07；LTS 2026-07；TierMem 2026-10）
- **Test-time learning / scaling**：在测试时从经验中持续学习或扩展探索 （ReasoningBank 2026-04；PersonaAgent 2026-07）
- **经验蒸馏**：从成功/失败轨迹提炼策略、技能或 insight （ReasoningBank 2026-04；MemEvolve 2026-07；ReMe 2026-07；UMEM 2026-07）

## 6. 遗忘、治理与安全：记忆的风险边界

- **显式删除 / 过滤**：delete、filter、prune 作为记忆操作 （AgeMem 2026-07；EMA 2026-07；Memory-R1 2026-07；ReMe 2026-07）
- **选择性遗忘评测**：测“何时应该忘”以及“忘了是否伤害任务” （MemoryAgentBench 2026-04；PersistBench 2026-07）
- **隐私提取攻击**：黑盒 query 也能提取 memory 中的敏感信息 （MEXTRA 2025-07）
- **Query-only 记忆注入**：不直接写 memory，只通过 query 让 agent 自己写入恶意记录 （MINJA 2025-12）
- **单次交互定向注入**：一次交互即可影响未来 topic 的输出 （InjecMEM 2026-10）
- **环境注入 poisoning**：只通过观察被污染网页/环境，就能跨 session、跨站污染 （eTAMP 2026-10）
- **Provenance / trust / write authorization**：记忆来源、写入权限和可信度必须可审计 （MEXTRA 2025-07；MINJA 2025-12；InjecMEM 2026-10；TierMem 2026-10；eTAMP 2026-10）
- **共享记忆权限与冲突**：多 agent/多用户共享记忆需要隔离、权限和冲突裁决 （G-Memory 2025-12；LTS 2026-07；MemRec 2026-07；PersistBench 2026-07）
- **安全防御需求**：TTL、删除、回滚、审计日志、检索过滤和内容隔离 （MEXTRA 2025-07；MINJA 2025-12；AgeMem 2026-07；PersistBench 2026-07；InjecMEM 2026-10；TierMem 2026-10；eTAMP 2026-10）
